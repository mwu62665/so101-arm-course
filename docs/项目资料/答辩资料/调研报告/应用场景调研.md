# SO-ARM101 具身智能桌面机械臂应用场景调研报告

**项目名称**：SO-ARM101 具身智能桌面机械臂课程设计  
**组别**：电子信息工程第十四组  
**完成日期**：2026-11-26  

---

## 1. 结论先行

本项目选定 **「桌面杯具 / 餐具归位整理」** 作为核心应用场景：机械臂通过双路视觉识别桌面上的杯具与餐盘，完成抓取并分别放置至指定宽松目标区域（杯具归位区 / 餐盘归位区），形成「识别 → 抓取 → 放置」的完整操作闭环。

选定该场景的核心依据在于其同时满足生活化价值与工程可落地性：桌面结构化环境便于 YOLO 稳定检测、目标物体轻小适合单臂夹爪抓取、任务结果肉眼可直接验证，且能够自然容纳「YOLO + 程序化抓取」与「ACT 模仿学习」双路线分工。在三个候选场景中，该方案兼顾现实需求叙事与单臂低成本实现可行性。

## 2. 场景筛选过程

依据四条工程筛选标准对候选场景进行横向评估：① 桌面结构化、YOLO 易于检测；② 物体轻小、适合单臂夹爪抓取；③ 能形成完整的「识别 → 抓取 → 放置」闭环；④ 单臂即可完成，且便于程序化抓取与模仿学习示教采集。

| 候选场景 | 生活化程度 | 技术可行性与单臂适配度 | 筛选结论 |
| --- | --- | --- | --- |
| ① 桌面物品分拣归类 | 中 | 高（规则物体可参数化抓取，稳定性最高） | 备选 |
| ② 桌面杯具 / 餐具归位整理 | 高 | 高（轻小易抓，兼顾程序化抓取与 ACT 模仿学习） | **选定主场景** |
| ③ 小零件上下料装配 | 低 | 低（毫米级装配精度要求高、卡死风险大） | 不采用 |

场景 ② 在生活化价值上显著优于 ①，在单臂实现可行性与风险可控性上远优于 ③，因此确定为主场景；场景 ① 可作为规则物体程序化抓取的验证备选。

## 3. 选定场景详述

### 3.1 任务定义

在规整桌面（模拟书桌或餐桌一角）上摆放若干杯具和餐盘，单臂机械臂通过视觉识别各类物体并逐个抓取，将杯具归位至杯具区、将餐盘归位至餐盘区（均采用宽松目标区域，降低几何容差敏感度），完成后桌面整洁有序。

### 3.2 选题意义与外部支撑

- **贴近真实社会需求**：餐桌布置与收拾、厨房整理是家庭服务机器人的典型高频任务，直接对应老年人及需生活协助人群的照护需求。马德里卡洛斯三世大学的 ADAM 双臂辅助机器人（IROS 2025）即以「布置餐桌、收拾餐具、递送水杯与药品、整理厨房」为核心目标，面向老年人与养老机构，印证了该场景的现实社会价值 [1]。
- **对标前沿学术课题**：北京大学董豪团队发表于 ICRA 2026 的研究 Imagine2Act 将「插花、放盘子、叠杯子、把笔插进笔筒」定义为「关系性物体重排」——既需要语义理解（「什么放哪里」），又面临严格的几何约束（如餐盘竖直插入碗架窄槽）[2]。本项目选定的杯具 / 餐具归位正是该前沿课题的单臂简化可验证版本。
- **契合开源硬件生态**：SO-ARM100/101 是 LeRobot 生态中低成本、可复现的主流开源平台，已有研究基于该平台完成了「ACT 模仿学习视觉自主抓取与搬运」验证 [3]，Hugging Face 社区亦有桌面多方块颜色分拣等开源策略参考 [4]。基于本项目实际采购的 ¥925.55 物料（SO-ARM101 6 舵机主臂套件 + 打印件 + 双路 1080P USB 摄像头）复现生活化桌面整理闭环，路线成熟、资料充分。

### 3.3 技术闭环设计

本项目采用 **LeRobot 原生架构**，由上位机统一完成感知、决策与舵机总线控制。抓取环节按物体几何复杂度采用双路线分工：**外形规则、坐标易参数化的物体交由 YOLO + 程序化抓取；抓握位姿敏感、姿态多样的物体（如杯具）交由 ACT 模仿学习**。顶层 LLM 仅承担轻量指令解析。

受限于单臂硬件配置（不采购主从双臂），本项目不采用 LeRobot 标准主从双臂遥操作方案 [5]，而是使用**组员自有手柄遥操作控制单臂**，在执行示教动作的同时同步记录 6 舵机关节角反馈与双相机图像帧。

| 环节 | 实现方式 | 对应技术选型与负责成员 |
| --- | --- | --- |
| 视觉识别 | 检测桌面上的杯具 / 餐盘，输出目标类别与 2D 像素位置 | YOLO（陈国豪） |
| 空间定位 | 由双路 2D 视觉结合手眼标定估计桌面抓取位姿 | 双路 HBV-F2170HD V22 1080P USB 摄像头（陈国豪） |
| 抓取路线 A：规则物体 | 位置明确、形状规则的物体，由检测中心与标定坐标解算抓取位姿，按预设轨迹执行抓放 | 程序化抓取（基础闭环 F2 · 毋涵 / 陈国豪） |
| 抓取路线 B：姿态多样物体 | 杯具等抓握位姿敏感、外形差异大的物体难以固定规则参数化，通过手柄遥操作采集示教（关节角 + 同步图像帧）训练 ACT 策略，由视觉观测直接生成抓取动作 | ACT 模仿学习（核心突破 F3 · 毋涵） |
| 语言指令解析 | 将自然语言翻译为受约束的结构化任务指令队列，路由并驱动上述抓取路线 | 顶层轻量 LLM（不碰图像、无 VLM · 巴昱霖） |

- **双路线分工依据**：规则物体交由程序化抓取，具备零训练、响应快、稳定性高的优势，保障基础闭环（F2）稳健落地；姿态多变的杯具交由 ACT 模仿学习，赋予系统对未示教位姿的泛化能力（F3）。两条路线并非技术堆砌，而是按任务难度各取所长、形成工程风险对冲。
- **示教数据规模**：ACT 策略训练通常需要约 50~100 条高质量示教数据 [3, 5]，装机后优先验证手柄遥操作控制的顺滑度与关节角/图像同步采集稳定性，再按实测效果调整采集规模。
- **客观验收判定**：桌面上的杯具与餐盘全部进入指定宽松归位区，且全过程无倾倒、无掉落，即可肉眼直观判定闭环成功。

### 3.4 工程风险与能力边界

- **几何约束与任务分级**：叠杯、窄槽插盘对位姿精度高度敏感，微小偏差即易导致失败 [2]。本项目优先稳定实现 L1–L2 级任务（单物搬运与宽松目标区域平面归位）；精密叠放与窄槽插接（L3）列为 L2 闭环跑通后的**进阶拓展（可选）**，不作为基础验收前置。
- **模仿学习的泛化边界**：ACT 策略仅在示教数据覆盖的物体外形、光照条件与摆放姿态范围内有效，对未见过的新物体或极端姿态仍可能失效；示教数据的覆盖度与一致性直接决定泛化上限。
- **单臂硬件约束**：本场景任务均设计为单臂可独立完成的抓取—放置操作，不涉及双臂协同（如 ADAM 的双手配合任务 [1]）。
- **场景定位边界**：本项目明确定位于「结构化桌面环境下的单一家务任务演示闭环」，不承诺面向复杂非标真实家庭环境的通用部署。

### 3.5 顶层 LLM 轻量指令解析边界

本项目顶层采用**轻量指令解析**架构：LLM 仅负责「自然语言 → 受约束结构化任务指令」的语义翻译与编排，不接触图像输入、不承担端到端运动控制，因此**不涉及 VLM / VLA**，开发周期可控且易于防幻觉校验。

- **模块职责范围（能做到）**：
  - **结构化意图翻译**：将自然语言映射为受约束 JSON 指令，例如「把红杯子放进杯架」→ `{action: "pick_and_place", target: "red_cup", zone: "cup_rack"}`。
  - **多步任务编排**：将复合指令拆解为有序执行队列（如「先收杯子，再把餐盘归位」），确定执行顺序与次数。
  - **参数补全与澄清**：补全默认速度、数量等安全参数；关键槽位缺失时主动发起澄清反问（如「请确认目标归位区域」）。
  - **白名单安全约束**：对词表之外的物体或未授权动作直接拦截拒绝，不向执行层透传非法命令。
- **系统能力边界（非本模块职责）**：
  - 不直接处理视觉图像、不做空间定位——目标位置完全由 YOLO 与双相机标定模块提供。
  - 不生成连续关节轨迹、不直接控制舵机——物理运动完全由程序化轨迹或 ACT 策略执行。
  - 不识别白名单外的新物体或新动作，泛化受限于预定义任务词表。
  - 不保证底层物理抓取成功率——物理成败取决于视觉检测、标定精度与策略泛化效果。
  - 针对大模型固有的幻觉风险，所有输出均须经过严格 Schema 校验后方可下发至控制层。

一言以蔽之，顶层 LLM 在本系统中扮演「解析自然语言、下发受约束结构化指令的调度层」，而非端到端视觉语言操作大模型，底层执行依然依托可靠的程序化抓取与 ACT 策略。

## 4. 应用场景总体定位总结

本项目面向生活化家庭服务场景，基于开源 LeRobot 架构与 SO-ARM101 低成本单臂平台（实付物料 ¥925.55），聚焦「桌面杯具 / 餐具归位整理」这一具体任务，构建「识别 → 抓取 → 宽松区域归位」完整闭环。选题既对应老年照护等真实社会需求与学术界「关系性物体重排」前沿课题，又契合桌面结构化、物体轻小、单臂可完成的工程条件。技术上通过「YOLO 程序化抓取 + 单臂示教 ACT 模仿学习」双路线分工兼顾稳健性与泛化能力，辅以顶层轻量 LLM 实现安全受控的自然语言交互，目标是在千元级预算内交付一套可复现、肉眼可验证的具身智能桌面操作演示系统。

## 5. 后续待落实事项

- **实验道具准备**：在 ¥74.45 预算结余内购置或自制标准化轻质杯具、餐盘及宽松归位区标识（结合结构建模岗协同适配）。
- **手柄遥操作与采集联调**：硬件到货组装完成（F0）后，第一时间实测手柄遥操作映射灵敏度、轨迹顺滑度及关节角与双相机帧的同步记录精度，并据此敲定 ACT 示教数据量。
- **指令词表与接口定稿**：明确轻量 LLM 的物体类别白名单、动作枚举、目标区域编码及 JSON Schema 校验规范，打通上位机调度接口。

SOCIAL DEMAND // 真实社会需求

直接对应老年照护与生活协助

餐桌布置与收拾是家庭服务机器人的高频刚需。马德里卡洛斯三世大学 ADAM 双臂辅助机器人（IROS 2025）即以“摆放餐具、递送水杯、整理厨房”为核心任务，面向老年人与养老院，印证该场景具有明确的社会价值。

ACADEMIC RELEVANCE // 学术难点简化版

对标「关系性物体重排」前沿课题

北大董豪团队 Imagine2Act（ICRA 2026）将“放盘子、叠杯子、插笔”定义为关系性物体重排，需兼顾语义归类与几何约束。本项目选定的杯具/餐具归位正是该前沿问题的单臂简化可验证版本。

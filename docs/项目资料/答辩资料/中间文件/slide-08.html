07 // CORE ARGUMENT · DUAL-ROUTE GRASPING

为什么两套抓取路线都要？按物体难度分工，兼顾稳健与泛化

不是技术堆砌 · 各取所长
基础闭环 (F2) + 泛化核心 (F3)
ROUTE A // PROGRAMMATIC GRASPING

路线 A：YOLO + 程序化抓取

基础闭环 · F2
双相机图像→ YOLO 检测框→ 手眼标定坐标→ 预设抓取轨迹
  • 适用物体：位置明确、外形规则、抓握姿态对方向不敏感的目标（如规则餐盘/垫块/固定位姿物体）。
  • 核心优势：零训练成本、响应快、可解释性强，只要手眼标定误差落在夹爪容差内即可高稳定性复现。
  • 为什么不能只靠它：杯具带手柄、姿态多样、同类别外形差异大，硬编码几何规则极易在偏转或遮挡时抓空。
TRAINING DATA
零示教（仅需 YOLO 权重）
EXECUTION MODULE
视觉检测 + 手眼标定 + 轨迹规划
ROUTE B // IMITATION LEARNING (ACT)

路线 B：单臂示教 + ACT 模仿学习

泛化核心 · F3
手柄遥操作示教→ 舵机反馈+相机帧→ ACT 策略训练→ 端到端泛化抓取
  • 适用物体：抓取位姿敏感、摆放角度多变的杯具等生活化物体——难以通过固定几何规则参数化，直接从人类示教学习动作序列。
  • 单臂手柄遥操作采集：预算约束下不采购主从双臂，使用组员自有手柄遥操作控制机械臂，同步记录 6 舵机关节角与双相机图像。
  • 示教规模与验收：采集约 50–100 条高质量示教；验收标准为对未示教过的杯子摆放位置实现自主抓取泛化。
KEY GATE
组装后首做手柄遥操作联调验证
EXECUTION MODULE
LeRobot 采集 + ACT 训练部署
ENGINEERING LOGIC 工程风险对冲设计：F2 程序化抓取确保基础闭环稳健落地；组装后优先完成手柄遥操作控制与同步采集联调，重点推进 F3 ACT 模仿学习泛化。

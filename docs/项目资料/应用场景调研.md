# 应用场景调研（初稿）

## 1. 结论先行

本项目选定 **「桌面杯具 / 餐具归位整理」** 作为具体应用场景：机械臂通过视觉识别桌面上的杯具、餐具，抓取后放到指定位置（杯具放入杯架 / 餐盘叠放区），形成「识别 → 抓取 → 放置」的完整闭环。

选它的理由：生活化、好讲故事（答辩时一句话能说清"这机器人在干什么、对谁有用"）、物体轻小好抓取、桌面结构化场景 YOLO 容易检测、单臂即可完成，且能同时容纳"程序化抓取"与"ACT 模仿学习"两条技术路线。这是三个候选场景里最稳、又兼顾生活化叙事的一个。

## 2. 场景选择过程

按四条标准筛选候选场景：①桌面结构化、YOLO 好检测；②物体轻小、夹爪好抓；③能形成"识别→抓取→放置"闭环；④单臂可完成、便于程序化抓取与模仿学习示教采集。

| 候选场景            | 生活化 | 技术可行性            | 结论     |
| --------------- | --- | ---------------- | ------ |
| ① 桌面物品分拣归类      | 中   | 高（最稳，规则物体可参数化抓取） | 备选     |
| ② 桌面杯具 / 餐具归位整理 | 高   | 高                | **选定** |
| ③ 小零件上下料装配      | 低   | 低（精度要求高、风险大）     | 不采用    |

场景②在"生活化"上强于①，在可行性上远强于③，兼顾叙事与落地，故定为主场景；①作为规则物体程序化抓取的备选，待核心闭环跑通后再定。

## 3. 选定场景详述

### 3.1 一句话描述

在桌面（如书桌、餐桌一角）上摆放若干杯子和餐盘，机械臂识别每个物体、逐个抓取，把杯子放进杯架、把餐盘叠放到指定区域，完成后桌面归位整齐。

### 3.2 为什么这件事值得做（意义）

- **生活化、贴近真实需求**：餐桌布置与收拾、厨房整理是家庭服务机器人的典型日常任务，直接对应老年人 / 需要生活协助人群的照护场景。马德里卡洛斯三世大学的 ADAM 双臂辅助机器人即以"布置餐桌、收拾餐具、递送水杯药品、整理厨房"为目标，面向老年人与养老院，说明这一场景有真实的社会需求支撑 [1]。
- **学术界正在攻的难点**：北京大学董豪团队 ICRA 2026 论文 Imagine2Act 把"插花、放盘子、叠杯子、把笔插进笔筒"定义为"关系性物体重排"——既要懂"什么放哪里"的语义，又要满足精确的几何约束（如盘子要竖直插进碗架窄槽）[2]。我们选的杯具 / 餐具归位正是这类任务的简化版本。
- **与开源生态对得上**：SO-ARM100/101 是 LeRobot 生态里低成本、可复现的主流平台，已有工作用它完成"基于 ACT 模仿学习的视觉自主抓取与搬运" [3]；Hugging Face 上也已有多方块颜色分拣等桌面操作模型 [4]。用这套硬件复现一个生活化家务场景，路线成熟、资料充分。

### 3.3 技术闭环（怎么实现）

抓取分两条路线，按物体难度分工：**能用坐标参数写死的交给 YOLO + 程序化抓取；写不死的（如抓杯子）交给 ACT 模仿学习**。顶层 LLM 只做轻量指令解析。本项目只有单臂、没有手柄，不走 LeRobot 标准的主从双臂遥操作示教；ACT 的示教数据用"人手掰臂、读取舵机反馈记录关节角 + 同步相机帧"的方式采集。

| 环节                  | 做法                                                                                                  | 对应本项目技术选型            |
| ------------------- | --------------------------------------------------------------------------------------------------- | -------------------- |
| 识别                  | 检测桌面上的杯具 / 餐盘，输出类别与像素位置                                                                             | YOLO（组员A 负责）         |
| 定位                  | 由 2D 像素估计物体在桌面的位置，供机械臂抓取                                                                            | 双相机（舵机套件外的双相机套餐）     |
| 抓取 A：可参数化物体         | 位置明确、形状规则的物体，用检测中心 + 手眼定位算抓取位姿，预设轨迹完成抓取与放置                                                          | 程序化抓取（组长 / 组员B）      |
| 抓取 B：YOLO 做不到的（如杯子） | 抓取位姿敏感、摆放姿态多样、同类形状差异大，参数规则搞不定 → 人手掰臂采示教（舵机反馈记关节角 + 相机帧）→ 训练 ACT 策略 → 给定视觉观测直接生成抓取动作，能泛化到没见过的位置 / 姿态 | ACT 模仿学习（组长 / 组员B）   |
| 语言指令                | 轻量指令解析：自然语言 → 受约束的结构化任务命令，驱动上面两条路线                                                                  | 顶层 LLM（不碰图像、不涉及 VLM） |

- **分工依据**：能写死坐标的用程序化抓取——稳、快、零训练；写不死的（精细、泛化）交给模仿学习。这也是答辩要讲清的"为什么两套都要"：不是技术堆砌，而是按物体难度各取所长。
- **示教数据量**：ACT 训练通常需要约 50~100 条示教 [2]，人手掰臂采集，开题后按实际效果调整。
- **可验证的完成判定**：桌面上的杯子全部进入杯架、餐盘完成叠放，且无倾倒 / 掉落，即可肉眼判定成功与否。

### 3.4 风险与边界（答辩要如实讲）

- **几何约束是难点**：叠杯、插盘对位姿精度敏感，微小偏差就可能失败 [2]。本项目先用"放置到较宽松的目标区域"降低难度，不追求研究级的窄槽插入。
- **模仿学习的泛化有限**：ACT 只在示教数据覆盖的物体与姿态范围内有效，没见过的杯子或极端摆放仍可能失败；示教数据的质量和数量直接决定上限，这是要投入的主要工作量。
- **单臂能力有限**：本场景均为单臂可完成的抓取—放置，不涉及双臂协同；双臂协调（如 ADAM 的工作 [1]）是进阶方向，不作为本项目目标。
- **不承诺通用家庭部署**：定位是"桌面结构化环境下的单一家务任务演示"，不是能适应任意家庭环境的服务机器人。

### 3.5 顶层 LLM 的能力边界（轻量指令解析最多做到什么地步）

本项目走**轻量指令解析**：LLM 只负责"自然语言 → 结构化任务命令"的翻译与编排，不接触图像、不做端到端控制，因此**不涉及 VLM / VLA**，一两周可出可演示的 demo。

- **能做到**：
  - 把一句话翻译成受约束的结构化命令，如"把红杯子放进杯架" → {动作: 抓取+放置, 目标类别: 红杯, 终点区域: 杯架}。
  - 任务编排：把一句话拆成有序多步（"先收杯子，再叠盘子"），决定先后顺序与重复次数。
  - 参数填充与澄清：补全速度 / 数量等参数；信息不全时反问（"放哪个区域？"）。
  - 安全约束：词表之外的物体或动作直接拒绝，不硬做。
- **做不到（如实讲）**：
  - 不直接看图像、不做视觉定位——"红杯子在哪"由 YOLO + 双相机给出。
  - 不生成连续关节轨迹、不直接控制舵机——运动由程序化抓取或 ACT 策略执行。
  - 不能识别词表外的新物体 / 新动作，泛化能力有限。
  - 不保证抓取成功——物理成败取决于检测、定位与策略效果。
  - 有幻觉风险，输出必须是结构化格式并做校验，不能直接当控制指令用。

一句话定位：LLM 在这里是"听懂人话、下达受约束命令"的指挥层，不是"看图干活"的通用智能；它让演示看起来像"语言指挥机器人干活"，底层仍是程序化抓取与 ACT 策略。

## 4. 答辩可用的话术（一段话）

> 我们做的是一个面向家庭服务场景的低成本具身智能机械臂：在桌面上识别杯具和餐盘，逐个抓取归位到杯架和叠放区，形成"识别—抓取—放置"的完整闭环。选中这个场景是因为它既生活化、能说清对谁有用——餐桌整理是家庭服务机器人的典型需求——又在技术上够得着：桌面结构化场景便于检测、物体轻小便于抓取、单臂即可完成。抓取分两条路：能用坐标参数写死的规则物体交给 YOLO 加程序化轨迹；抓杯子这类 YOLO 做不到的精细、泛化操作，用 ACT 模仿学习——人手掰臂采集示教数据训练策略。顶层用一个轻量 LLM 把自然语言翻译成受约束的任务命令，不涉及视觉语言大模型。我们用开源 LeRobot 框架和 SO-ARM101 机械臂复现这条路线，目标是在有限成本下做出可复现、肉眼可验证的家务操作演示。
